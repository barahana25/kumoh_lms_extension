# Chrome 웹스토어 등록 문구 — 금오 LMS 알리미 v0.3.0

각 항목의 본문을 그대로 복사해 붙여 넣으면 됩니다. 1,000자 제한 항목은 모두 제한 안에 들어갑니다.

## 상세 설명 (스토어 '설명' 칸)

금오공과대학교 LMS(Canvas)의 과제·공지·강의자료를 한곳에 모아 보여주고, 새 소식이 올라오면 알려주는 확장 프로그램입니다.

"과제 마감이 언제였지?", "그런 공지가 있었어?" 하고 LMS를 매번 뒤져 볼 필요 없이, 브라우저 오른쪽 위 아이콘 하나로 확인하세요.

■ 주요 기능

1. 강의 한눈에 보기
- 이번 학기 수강 과목을 카드로 모아 보여줍니다.
- 과목마다 새 공지 수와 마감 임박 과제 수를 표시합니다.
- 지난 학기는 학기를 고를 때만 불러옵니다.

2. 과제 마감 관리
- 마감이 가까운 순서로 D-DAY, D-1처럼 남은 기간을 보여줍니다.
- 제출한 과제는 따로 표시하고, 미제출 과제만 모아 볼 수 있습니다.
- 캘린더에서 날짜별 마감 과제를 확인할 수 있습니다.

3. 새 공지·강의자료 알림
- 30분마다 새 공지, 새 과제, 새 강의자료를 확인해 데스크톱 알림으로 알려줍니다.
- 마감 3일 전, 1일 전, 당일에 한 번 더 알려줍니다.
- 읽지 않은 공지 수를 아이콘 배지로 보여줍니다.

4. 강의자료 자동 다운로드 (선택)
- 켜 두면 새 강의자료를 다운로드 폴더 아래 과목별 폴더에 저장합니다.

5. LMS → Canvas 바로 이동, 로그인 유지
- lms.kumoh.ac.kr에 로그인하면 곧바로 Canvas로 이동합니다.
- 브라우저가 켜져 있는 동안 LMS 로그인이 풀리지 않게 유지합니다.
- 두 기능 모두 설정에서 끌 수 있습니다.

■ 사용 방법

1. 확장 프로그램을 설치합니다.
2. 브라우저에서 금오공대 LMS(Canvas)에 한 번 로그인합니다.
3. 아이콘을 누르면 끝입니다. API 키를 직접 만들어 붙여 넣을 필요가 없습니다.

■ 개인정보

- 가져온 정보는 모두 사용자의 브라우저 안에만 저장합니다.
- 개발자 서버나 제3자에게 어떤 정보도 보내지 않습니다. 통신 대상은 canvas.kumoh.ac.kr, lms.kumoh.ac.kr 두 곳뿐입니다.
- 공용 PC보다는 개인 PC에서 사용해 주세요.

※ 이 확장 프로그램은 금오공과대학교의 공식 프로그램이 아니며, 학생이 개인적으로 만든 도구입니다.

## 전용 목적

금오공과대학교 LMS(Canvas)를 쓰는 학생이 수강 과목의 과제·공지·강의자료를 놓치지 않도록 돕는 도우미입니다. 사용자가 로그인한 금오공대 Canvas에서 이번 학기 과목의 과제, 공지, 강의자료를 가져와 팝업에 모아 보여주고, 새 글이 올라오거나 과제 마감이 다가오면 알림을 띄웁니다. 같은 목적을 위해, 학교 LMS 첫 화면(lms.kumoh.ac.kr)에 로그인하면 곧바로 Canvas로 이동시키고 LMS 로그인이 도중에 풀리지 않게 유지합니다. 모든 기능은 금오공대 LMS 두 도메인(canvas.kumoh.ac.kr, lms.kumoh.ac.kr)에서만 동작합니다.

## alarms 사용 근거

새 공지·과제·강의자료를 확인하기 위해 사용자가 정한 주기(최소 30분)마다 백그라운드에서 금오공대 Canvas를 조회하는 데 사용합니다. 또 LMS 로그인이 만료되기 전에 토큰을 갱신하기 위해 5분마다 만료 시각을 확인하는 데 사용합니다. 서비스 워커는 언제든 종료될 수 있어서, 주기 작업을 안정적으로 실행하려면 alarms가 필요합니다.

## notifications 사용 근거

수강 과목에 새 공지, 새 과제, 새 강의자료가 올라왔을 때와 과제 마감이 3일·1일·당일로 다가왔을 때 데스크톱 알림을 띄우는 데 사용합니다. Canvas 로그인이 풀려 새 소식을 확인할 수 없을 때 한 번 안내하는 데도 사용합니다. 알림은 이 확장 프로그램의 전용 목적(과제·공지를 놓치지 않게 하기)을 위한 것이며 광고나 홍보에는 쓰지 않습니다.

## storage 사용 근거

Canvas에서 가져온 과목·과제·공지·강의자료 목록을 팝업에서 바로 보여주기 위해 캐시로 저장하고, 이미 알린 글을 다시 알리지 않도록 확인한 글의 ID를 기록하는 데 사용합니다. 사용자 설정(확인 주기, 자동 다운로드 여부, 저장 폴더, LMS 바로가기 설정)과 읽음 표시도 저장합니다. 또 Canvas API 토큰을 저장하며, 같은 Chrome 계정의 기기끼리 토큰을 하나만 쓰도록 storage.sync에 둡니다. 모든 데이터는 브라우저 저장소에만 있고 개발자 서버로 보내지 않습니다.

## downloads 사용 근거

사용자가 설정에서 '강의자료 자동 다운로드'를 켠 경우에만, 새로 올라온 강의자료를 다운로드 폴더 아래 과목별 폴더(예: KumohLMS/과목명/강의자료/파일명.pdf)에 저장하는 데 사용합니다. 같은 파일을 두 번 받지 않도록 downloads.search로 이미 받은 파일인지 확인합니다. 실행 파일(.exe, .js, .py 등)은 자동으로 받지 않습니다. 기본값은 꺼져 있습니다.

## cookies 사용 근거

두 가지 용도로만 사용합니다. (1) 사용자가 API 키를 직접 만들지 않아도 되도록, 로그인된 canvas.kumoh.ac.kr 세션의 CSRF 쿠키(_csrf_token)를 읽어 Canvas 공식 API(/api/v1/users/self/tokens)로 이 확장 전용 API 토큰을 발급합니다. (2) LMS 로그인 유지를 위해 lms.kumoh.ac.kr의 accessToken·refreshToken 쿠키를 읽고, 만료 전에 학교 서버에서 재발급받은 새 토큰으로 같은 쿠키 값을 갱신합니다. 다른 사이트의 쿠키에는 접근하지 않으며, 쿠키 값을 외부로 보내지 않습니다.

## declarativeNetRequestWithHostAccess 사용 근거

금오공대 LMS 두 도메인에서만 쓰는 규칙 세 가지입니다. (1) 정적 규칙: https://lms.kumoh.ac.kr/ 로 들어오면 학교 LMS의 실제 첫 화면인 /ko로 이동시킵니다. (2)(3) 세션 규칙: 이 확장의 서비스 워커가 보내는 요청(탭이 아닌 요청, tabIds: TAB_ID_NONE)에 한해, Canvas 토큰 발급 요청과 LMS 토큰 재발급 요청의 Origin·Referer 헤더를 각 학교 사이트 주소로 바꿉니다. 학교 서버가 chrome-extension:// Origin을 거부하기 때문입니다. 사용자가 탭에서 보내는 요청이나 다른 사이트의 요청은 건드리지 않습니다.

## 호스트 권한 사용 근거

https://canvas.kumoh.ac.kr/* — 금오공대 Canvas LMS입니다. Canvas 공식 REST API로 사용자의 수강 과목, 과제(제출 여부 포함), 공지, 강의자료 목록과 프로필(이름·학번)을 가져와 팝업에 보여주고 새 글 알림을 만듭니다. 로그인된 세션으로 이 확장 전용 API 토큰을 발급·삭제하는 데도 사용합니다.

https://lms.kumoh.ac.kr/* — 금오공대 LMS 포털입니다. 콘텐츠 스크립트가 로그인 상태를 확인해 Canvas로 바로 이동시키고, 백그라운드가 학교 LMS API(lms.kumoh.ac.kr:82)로 로그인 토큰을 재발급해 로그인을 유지합니다.

두 도메인 외의 사이트에는 접근하지 않습니다.
